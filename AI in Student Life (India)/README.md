# AI in Student Life (India) - Data Analysis

## Features
- Load and explore dataset with Pandas
- Display dataset shape, summary info, and descriptive statistics
- Identify missing values per column
- Filter and group data for insights (streams, states, AI tools)
- Calculate average usage time for specific streams
- Create new derived columns (Daily Usage Hours)
- Identify top states with highest AI usage
- Generate multiple visualizations:
  - Bar chart (Daily Usage Time vs Impact on Grades)
  - Bar chart (Students per Stream)
  - Pie chart (Distribution of AI Tools)
  - Histogram (Distribution of Daily Usage Time)
  - Bar chart (Impact on Grades)

## Program Flow
1. Load dataset from CSV file
2. Perform basic exploration (head, shape, info, describe, missing values)
3. Apply filtering and grouping for insights
4. Create new calculated columns
5. Generate statistical summaries
6. Visualize insights using bar charts, pie charts, and histograms
7. Display results for interpretation

## Concepts Used
- Pandas for data loading, cleaning, and analysis
- NumPy for numerical operations
- Seaborn and Matplotlib for data visualization
- DataFrame operations (`head`, `info`, `describe`, `isnull`, `groupby`, `value_counts`)
- Statistical calculations (mean, counts)
- Plotting techniques (bar chart, pie chart, histogram)
- User-defined filtering and grouping
